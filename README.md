# Помічник рекрутера для work.ua

Інструмент, який обходить сторінки пошуку резюме на work.ua, оцінює кандидатів
за допомогою Gemini і складає результат у Google Таблицю.

## Чому саме так, а не через Google Apps Script

Перевірено дослідом (`перевірка-доступу.gs`): Apps Script не може завантажити
сторінки work.ua. Сайт стоїть за Cloudflare, і той відповідає:

> Перевірка надійності підключення до сайту. Work.ua має перевірити безпеку
> вашого з'єднання, перш ніж продовжити. Enable JavaScript and cookies to
> continue. Ваша IP адреса: 34.116.22.3

`34.116.22.3` — адреса сервера Google. Cloudflare бачить запит із дата-центру
і вимагає виконати JavaScript. Apps Script не браузер і виконати його не може —
ні з логіном, ні з підміною User-Agent (перевірено обидва варіанти, обидва 403).

Тому збір сторінок відбувається **в браузері рекрутера** через userscript
(Tampermonkey): там уже є і житловий IP, і пройдена перевірка Cloudflare,
і сесія роботодавця.

## Будова

| Частина | Де працює | Що робить |
|---|---|---|
| Збирач | Браузер (Tampermonkey) | Гортає сторінки пошуку, збирає кандидатів |
| Оцінювач | Браузер → Gemini API | Виставляє бал 0–100 за описом вакансії |
| Записувач | Apps Script у таблиці | Пише рядки в «Кандидати» та «Історію» |

Apps Script залишається в справі — він лише не ходить назовні, а пише сам у себе.

## Що з'ясовано про сторінки work.ua

**Список резюме**
`https://www.work.ua/resumes-<місто>-<запит>/?experience=165&period=5&page=N`
Фільтри — у шляху та в query. Пагінація — параметр `page`. Номер останньої
сторінки видно з блоку пагінації вже на першій сторінці (наприклад, 423).

**Посилання на резюме**
`https://www.work.ua/resumes/16274539/?puid=6296`
Цифри — постійний номер резюме, ключ для дедуплікації. `?puid=` — мітка
переходу, відкидається.

**Картка у списку** вже містить: бажану посаду, перелік «розглядає посади»,
ім'я, вік, місто, освіту, тип зайнятості, два останні місця роботи з
тривалістю, час оновлення. Цього достатньо для чорнової оцінки, тож повне
резюме відкривається лише для тих, хто пройшов поріг.

**Сторінка резюме** — близько 3000 символів тексту. Професійна частина
(досвід, освіта) видна завжди. Прізвище, телефон, пошта і світлина закриті
й доступні тільки зареєстрованому роботодавцю — ми їх не збираємо.

## Файли

- `збирач-крок3.user.js` — userscript для Tampermonkey: обхід сторінок і збір
  кандидатів. Поки без оцінювання і без запису в таблицю.

## Обмеження, про які треба пам'ятати

- Широкий пошук — це сотні сторінок (5913 кандидатів = 423 сторінки).
  Повний обхід займає десятки хвилин, тож потрібні обмеження і відновлення
  після зупинки.
- Безкоштовний тариф Gemini має денну межу запитів. Тому оцінювання йде
  пачками по 15–20 кандидатів за один запит, а не по одному.
- У Gemini не передаються контактні дані — тільки професійна частина.
- Верстка work.ua колись зміниться. Збирач має падати голосно
  («на сторінці 0 кандидатів»), а не тихо приносити порожню таблицю.
